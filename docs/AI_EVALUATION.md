- MVVP (Phase A4, binding): swapping the judge model or substantially rewriting a prompt REQUIRES the three-piece suite before any "more accurate" claim: (1) agreement — keyed golden/practice suites + rater-pack κ/α (`node scripts/score-rater-pack.mjs`, graduation κ≥0.6); (2) consistency — 3-repeat stdev ≤1.0 with no readiness flips; (3) bias audit — position/verbosity/agreeableness triplets (`evals/bias-cases.json`, drift>20 flags) with abstain (422/empty evidence) counted separately, never merged into pass rate. All keyed legs go through the C1 quota ledger first and are logged in EVAL_REPORT §5.x. A single breach records variance; prompts/tests are NEVER tuned on n=1.
